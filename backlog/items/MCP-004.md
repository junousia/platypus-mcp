# MCP-004 Implement work dispatch skeleton

## Goal

Implement the first safe work dispatch skeleton without binding to a specific harness runtime yet.

## Implementation Contract

Replace `dispatch_next_work` stub with deterministic backlog selection, task record creation, and event emission. Do not run arbitrary shell or workers yet. Return a task id and next action for external harness execution.

## Acceptance

- Runnable backlog item selection creates a persisted task record.
- Task started/queued event is persisted.
- Tool returns structured skipped result when no runnable items exist.
- No arbitrary command execution is introduced.
- `make check` passes.
