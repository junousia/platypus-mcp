# MCP-044 Add SQLite ProjectState implementation shell

## Goal

Make SQLite one implementation of ProjectState while preserving current behavior.

## Implementation Contract

Introduce SqliteProjectState as the first backend implementation. It may delegate to existing storage internals temporarily, but callers should be able to construct and use it through the ProjectState abstraction.

## Acceptance

- SqliteProjectState implements the ProjectState trait for at least inspection and lifecycle scaffolding needed by later migrations.
- SQLite-specific setup and schema details stay inside SQLite/backend modules.
- Existing MCP tools continue to behave the same.
- Tests cover opening a project state through the SQLite backend shell.
