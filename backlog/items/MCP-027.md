# MCP-027 Add standalone MCP tool invocation helper

## Goal

Make it easy to exercise Platypus MCP tools from the repository without writing ad hoc JSON-RPC scripts.

## Implementation Contract

Add a small repository-supported command path for invoking one MCP tool against the local stdio server or in-process server with JSON arguments. Keep it deterministic, typed enough to validate JSON inputs and surface structured tool results, and avoid bypassing the MCP tool contract. Document the workflow as a development and smoke-testing aid, not as the primary product UI.

## Acceptance

- A developer can call a named MCP tool with JSON arguments from the repo command line.
- The helper prints the structured tool result in readable JSON and returns non-zero for failed tool results or protocol errors.
- The implementation reuses the existing MCP tool/server contract instead of duplicating business logic.
- Tests cover at least inspect_work_queue and one mutating tool against an isolated temp project.
- Documentation shows how to use the helper for local smoke testing.
