# MCP-077 Manual handoff lifecycle shortcut

## Goal

Let same-session MCP hosts finish manual handoff assignments without a separate `start_worker_task` call when the assignment was already prepared or claimed.

## Implementation Contract

Teach `finish_work` to auto-start prepared or claimed manual-handoff assignments by default, recording the lifecycle event before completion. Keep explicit start tools for real worker/session boundaries. Return clear output when auto-start occurred.

## Acceptance

- `finish_work` can complete a prepared or claimed manual-handoff assignment without a prior `start_worker_task`.
- Auto-start is recorded as a task/assignment event.
- The existing explicit `start_worker_task` path still works.
- Host guidance explains when explicit start is useful versus optional.
