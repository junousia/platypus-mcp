# MCP-001 Add durable local state store

## Goal

Add a durable local storage foundation for MCP-managed tasks, events, and findings.

## Implementation Contract

Introduce a small SQLite-backed storage module with schema initialization under `.platy/platypus.sqlite3`. Keep storage independent from RMCP server wiring and expose typed Rust functions for later tools. Use project-root containment and deterministic errors.

## Acceptance

- Storage initializes inside the configured project root without panicking.
- Schema includes tables for findings, task events, and metadata versioning.
- Tests cover fresh initialization and repeated initialization.
- `make check` passes.
