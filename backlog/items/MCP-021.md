# MCP-021 Add integration evidence and reconciliation coverage

## Goal

Make worker result integration auditable and make reconciliation prove the
work item lifecycle is complete.

## Implementation Contract

Record durable integration events and evidence after successful integration.
Update reconciliation so completed tasks are not considered fully handled until
their integration evidence and closure trailers are present.

## Acceptance

- Successful integration records task/project events and evidence.
- Reconciliation reports completed tasks that were never integrated.
- Reconciliation reports integration commits missing required Platypus trailers.
- An integrated task with verification evidence reconciles cleanly.
- `make check` passes.
