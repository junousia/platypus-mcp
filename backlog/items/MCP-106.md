# MCP-106 Suppress empty implementation contract noise

## Goal

Make simple direct backlog items cleaner when implementation_contract is intentionally omitted.

## Implementation Contract

Adjust backlog rendering and validation so omitted implementation_contract does not create confusing empty Markdown noise. Preserve schema validity and make the intentional empty/default behavior explicit in docs and previews.

## Acceptance

- create_backlog_items no longer renders a visually confusing blank Implementation Contract section for intentionally minimal items, or renders a clear placeholder.
- Validation still accepts existing items and strict required sections where needed.
- Preview output matches written output.
- Tests cover omitted and provided implementation_contract cases.
