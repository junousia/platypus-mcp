# MCP-108 Clarify completion tool boundaries and aliases

## Goal

Reduce confusion between complete_backlog_item, finish_work, complete_worker_task, and complete_worker_execution.

## Implementation Contract

Audit tool descriptions, toolsets, guidance resources, and generated docs so each completion tool has an unambiguous role. Friendly aliases should be labelled as aliases, and direct versus worker-handoff completion should be impossible to confuse from schema descriptions.

## Acceptance

- Direct work guidance consistently points to complete_backlog_item only.
- Worker handoff guidance consistently points to finish_work or clearly documents low-level complete_worker_execution aliases.
- Tool descriptions identify aliases and preferred high-level tools.
- Tests or doc assertions cover the updated wording for completion tools.
