# MCP-083 Backlog creation preview and quick create

## Goal

Reduce backlog authoring friction for simple item creation while preserving strict validation and atomic writes for larger batches.

## Implementation Contract

Add a preview path for `create_backlog_items` and a compact quick-create surface for common fields. Preview must allocate deterministic would-be IDs, validate dependencies and schema without writing files, and return the exact markdown targets that would be created. Quick create must expand to the same strict internal item model as full creation.

## Acceptance

- Hosts can preview a batch without changing the repository.
- Preview reports the same validation errors as real creation.
- Quick create supports title, goal, type, priority, area, owned surfaces, and acceptance criteria.
- Quick create output is indistinguishable from full create after validation.
