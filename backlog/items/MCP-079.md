# MCP-079 Backlog item update tool

## Goal

Allow hosts to correct or refine existing backlog items through a structured MCP tool instead of editing markdown by hand.

## Implementation Contract

Add an `update_backlog_item` tool that loads one existing item, applies a typed patch for supported frontmatter and body sections, validates the result before write, and rolls back on failure. The tool must preserve unknown-free strict schema behavior, reject updates to closed items unless explicitly forced, and return exact changed fields plus recovery guidance.

## Acceptance

- Hosts can update title, priority, type, area, epic, dependencies, owned surfaces, external refs, execution path, planning gate, goal, implementation contract, and acceptance criteria.
- Invalid updates fail without changing the item file.
- Closed items are protected by default with a clear override path.
- Tests cover success, validation failure rollback, dependency validation, and closed-item protection.
