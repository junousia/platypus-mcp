# MCP-140 Harden host bootstrap smoke tests

## Goal

Add or expand first-class smoke coverage for supported MCP host bootstrap targets so Codex, Claude, OpenCode, and Pi setup regressions are caught before release.

## Implementation Contract

Inspect existing bootstrap helpers and tests, then add focused smoke coverage for generated host configuration and core startup expectations. Keep tests deterministic and local-only; do not require installed external host binaries.

## Acceptance

- Smoke coverage exercises representative bootstrap output for Codex, Claude, OpenCode, and Pi.
- Tests verify paths/config snippets that are important for host startup without depending on external host processes.
- Documentation remains aligned with the supported bootstrap commands.
- `make check` passes.
