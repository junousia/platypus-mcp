# MCP-037 Draft external report payloads

## Goal

Add a read-only MCP tool that drafts provider-neutral report payloads for
external trackers from local backlog, task, evidence, and finding state.

## Implementation Contract

The tool must not call GitHub, Linear, Jira, or any other provider directly.
It should inspect local state, select the external reference to report against,
and return a typed draft payload with provider, kind, external id, report
intent, title/body or markdown, referenced local evidence, and safety notes.
It must handle missing external refs, missing evidence, and unsupported report
intents as structured skipped or failed results.

## Acceptance

- MCP exposes a read-only typed tool for drafting external report payloads.
- Drafts can represent at least comment, status/link, follow-up finding, and
  closure-intent report types without provider-specific write behavior.
- The response includes local evidence/task/backlog references used to build
  the draft.
- Tool output contains no credentials and redacts unsafe metadata.
- Tests use fixture/local data only and require no live provider.

## Notes

This is the first executable step after the external reporting policy docs. It
keeps write-back separate from drafting so hosts can review payloads before any
external mutation is attempted.
