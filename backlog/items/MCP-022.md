# MCP-022 Add lifecycle smoke scenario

## Goal

Add a deterministic end-to-end smoke scenario that exercises the full MCP
lifecycle without live provider dependencies.

## Implementation Contract

Build the scenario through MCP tools using fake or local fixtures only. The
flow must cover project initialization, backlog creation, dispatch, worker
handoff, fake worker result, verification evidence, integration, reconciliation,
and cleanup.

## Acceptance

- One stdio-level test exercises the full lifecycle through public MCP tools.
- The scenario uses no live Codex or Claude provider.
- Failures identify the lifecycle stage that broke.
- `make check` passes.
