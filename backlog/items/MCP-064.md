# MCP-064 Actionable recovery guidance for backlog authoring

## Goal

Make backlog authoring failures guide the caller to the exact recovery step instead of returning generic setup inspection advice.

## Implementation Contract

Improve structured errors and next actions for recoverable backlog authoring failures. Focus first on unknown epics, invalid dependencies, invalid enum values, duplicate IDs, missing backlog directories, and invalid external refs. The tool should use information it already has, such as existing epics and valid enum values, to produce specific recovery guidance.

## Acceptance

- Unknown epic failures name the missing epic, list existing epics, and suggest creating `backlog/epics/<id>.md` or using an existing epic.
- Invalid priority and type failures include the rejected value and all accepted values.
- Invalid dependency failures identify the missing dependency and explain whether to create it first or remove the dependency.
- Duplicate item failures include the existing item path and suggest omitting `id` for automatic allocation when appropriate.
- Missing directory failures suggest `init_project` or the exact directory that must exist.
- Tests cover unknown epic guidance and at least two other recoverable authoring failures.
