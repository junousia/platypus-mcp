# MCP-026 Add executable work queue inspection

## Goal

Give MCP hosts one read-only tool for choosing runnable backlog work while
seeing task-plan readiness and the recommended next tool.

## Implementation Contract

Add a typed `inspect_work_queue` MCP tool that combines runnable backlog
candidates with task-plan state. It must remain deterministic and read-only,
support bounded queue output, and optionally require a valid task plan before
recommending dispatch.

## Acceptance

- MCP hosts can inspect runnable backlog items and their task-plan state in one
  call.
- The tool reports missing, invalid, and valid task plans with structured
  details.
- The tool recommends `draft_task_plan`, `validate_task_plan`, or
  `dispatch_next_work` based on queue state.
- The stdio MCP protocol test covers the end-to-end tool behavior.
- Documentation and host guidance describe when to use the tool.
- `make check` passes.
