# MCP-105 Add compact inspect_session mode

## Goal

Reduce routine startup payload size while preserving verbose diagnostic detail on demand.

## Implementation Contract

Add an explicit compact/default or detail mode to inspect_session that returns the essential scaffold health, queue_state, next_action, recommended tool, and schema hints without embedding the full detailed queue unless requested.

## Acceptance

- inspect_session supports a documented compact/default response shape and verbose detail mode.
- Compact output includes scaffold readiness, queue_state, recommended_tool, next_action, and schema hints.
- Verbose mode preserves current diagnostic detail for recovery and debugging.
- Tests cover compact and verbose inspect_session behavior.
