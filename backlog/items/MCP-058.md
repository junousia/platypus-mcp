# MCP-058 Make git readiness and worktree recovery foolproof

## Goal

Make fresh-project and dirty-manager-workspace failures explain exactly what blocks worktree dispatch and how to recover without source inspection.

## Implementation Contract

Improve git readiness diagnostics across worktree creation, doctor snapshots, and safe-action guidance. Detect missing git repositories, unborn HEAD, and dirty manager workspace states before confusing downstream errors. Return structured recovery next actions that tell users whether to run git init, create an initial commit, commit/stash/discard manager changes, or choose another base ref. Do not auto-run destructive git commands.

## Acceptance

- Fresh directories without .git return a structured git initialization recovery action before worktree dispatch.
- Git repositories with unborn HEAD report that an initial commit is required and include the exact safe next action.
- Dirty manager workspace failures identify that integration or dispatch is blocked by manager changes and suggest commit, stash, or discard review paths.
- doctor_snapshot and next_safe_action surface the same readiness guidance.
- Tests cover missing repo, unborn HEAD, and dirty manager workspace recovery guidance.
