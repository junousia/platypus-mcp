# MCP-068 Planning-only goal intake mode

## Goal

Make `plan_goal_work` respect planning intent so a planning-only conversation does not push the caller toward immediate dispatch.

## Implementation Contract

Add an `intent` field to `plan_goal_work` with values `auto`, `planning_only`, and `ready_to_execute`. In `planning_only`, return non-mutating planning and backlog-authoring next actions. In `ready_to_execute`, keep the existing `start_goal_work` recommendation. In `auto`, infer planning-only intent from phrasing such as "plan", "design", "shape backlog", or "create backlog items"; otherwise preserve current execute-ready guidance.

## Acceptance

- `plan_goal_work` with `intent=planning_only` recommends planning/backlog tools and does not recommend dispatch.
- `plan_goal_work` with `intent=ready_to_execute` preserves the current tracked execution recommendation.
- `intent=auto` treats planning phrasing as planning-only and implementation phrasing as ready-to-execute.
- Returned `recommended_arguments` match the recommended tool for the selected intent.
- Tool schema and host guidance document the intent values and defaults.
- Tests cover explicit planning-only, explicit ready-to-execute, and auto inference.
