# MCP-078 Goal workflow verification and classification polish

## Goal

Remove confusing friction in the goal workflow surfaced by Codex, Claude, and OpenCode feedback.

## Implementation Contract

Expand verification allowlist guidance for common Python workflows, fix inaccurate single-surface classification reasons, and add a compact manual-handoff checklist to goal-start output. Keep command execution allowlisted and bounded.

## Acceptance

- Python verification commands are either accepted safely or rejected with an allowed wrapper suggestion.
- Multi-surface goals do not produce single-surface classification reasons.
- `start_goal_work` output includes a concise manual-handoff checklist when dispatch prepares a manual handoff.
- Tests cover Python verification guidance and multi-surface classification wording.
