# MCP-028 Add deterministic planning mode policy

## Goal

Classify runnable backlog items as direct, standard, or full planning mode so inspect_work_queue only blocks dispatch when extra planning is actually required.

## Implementation Contract

Add deterministic planning policy logic based on backlog metadata, owned surfaces, type, area, and high-risk surfaces. Expose the classification in work queue output and a read-only MCP tool. Preserve strict task-plan validation for standard/full items, but allow direct items to dispatch without a plan. Keep reasons structured and testable.

## Acceptance

- Each work queue item includes required planning mode and reasons.
- Direct items can be dispatch-ready without a task plan even when planning policy is enabled.
- Standard and full items require a valid task plan before dispatch.
- A read-only MCP tool can classify one item or the runnable queue without mutating state.
- Tests cover direct, standard, and full classification paths.
- Documentation describes the policy and when design/task plans are required.

## Notes

Created after discussing deterministic planning requirements for design/task plan documents.
