# MCP-098 Prioritize direct completion loop in queue guidance

## Goal

Make direct-ready queue output steer agents to edit, verify, and complete directly instead of treating prepare_work as the required next transition.

## Implementation Contract

Use structured fields rather than prose-only guidance. direct_ready must recommend complete_backlog_item as the durable transition, expose a compact minimal direct loop, and leave prepare_work as optional response-local guidance only.

## Acceptance

- inspect_work_queue and inspect_session recommend complete_backlog_item for direct_ready work.
- Direct-ready responses include a structured minimal_direct_loop with inspect, edit, verify, and complete steps.
- prepare_work remains available but is labelled optional guidance-only for direct work.
- Host guidance docs and generated project guidance match the structured API behavior.
- Tests cover the new direct-ready recommendation and minimal direct loop fields.
