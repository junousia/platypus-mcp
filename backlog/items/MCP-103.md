# MCP-103 Add deferred-schema bootstrap and core schema preload

## Goal

Reduce cold-start friction for hosts that defer MCP schemas by documenting the real first step and exposing a compact core schema preload surface.

## Implementation Contract

Add explicit deferred-schema bootstrap guidance before workflow decision tables, and add a compact resource or equivalent host-neutral surface for the core tools commonly needed at session start. Keep advisory toolsets available, but make the canonical startup path obvious for Codex, Claude, OpenCode, and similar hosts.

## Acceptance

- Host guidance explains what to do before inspect_session when the host has deferred schemas.
- A core schema/preload surface covers inspect_session, inspect_work_queue, create_backlog_items, complete_backlog_item, prepare_work, and record_verification_evidence or explains why the host must use search instead.
- Docs distinguish human-readable guidance from machine-oriented toolset metadata.
- Tests cover the new bootstrap/preload guidance or resource output.
