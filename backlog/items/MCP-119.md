# MCP-119 Release version 0.2.0

## Goal

Prepare the repository for the `v0.2.0` GitHub release by aligning the Rust crate and npm package versions.

## Implementation Contract

Update the package metadata that controls crates.io and npm release versions. Keep the release workflow unchanged unless the version bump exposes a release-blocking issue.

## Acceptance

- `Cargo.toml` declares `platypus-mcp` version `0.2.0`.
- `Cargo.lock` reflects the local `platypus-mcp` package version `0.2.0`.
- `package.json` declares `platypus-pi` version `0.2.0`.
- Backlog validation and repository verification pass before the GitHub release is created.
