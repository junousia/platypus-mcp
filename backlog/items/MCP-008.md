# MCP-008 Add runner claim loop skeleton

## Goal

Provide a local runner skeleton that claims queued tasks, prepares their
workspace and bundle, and records lifecycle events without executing real
workers yet.

## Implementation Contract

Add a bounded runner entrypoint with max-task and dry-run controls. It must
claim tasks through the same lifecycle API exposed by MCP, prepare workspaces
and bundles, transition task state predictably, and stop with explicit summary
data. Keep worker harness execution out of this item.

## Acceptance

- Runner can claim one queued task and prepare its workspace and bundle.
- Runner records start, preparation, and stop events.
- Runner stops cleanly when no tasks are queued.
- Tests cover bounded execution and no-work cases.
