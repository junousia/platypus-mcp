# MCP-061 Create backlog items from minimal goals

## Goal

Reduce backlog authoring friction so a simple user goal such as "scaffold frontend" can become one valid structured backlog item in one MCP call.

## Implementation Contract

Keep the persisted markdown schema strict, but let create_backlog_item derive safe default title, goal, implementation contract, and first acceptance criterion when the host provides at least a meaningful title or goal. Preserve explicit-field behavior, validation, id allocation, and schema guidance for truly empty input.

## Acceptance

- create_backlog_item with only a goal creates valid backlog markdown.
- create_backlog_item with only a title creates valid backlog markdown.
- Generated fields are deterministic, conservative, and visible in the written item.
- Empty input still fails with clear schema guidance.
- Tests cover minimal goal creation and existing strict validation behavior.
