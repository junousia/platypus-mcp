# MCP-024 Add MCP resources and prompts for host guidance

## Goal

Help MCP hosts such as Codex and Claude discover the intended Platypus workflow
without relying only on chat instructions.

## Implementation Contract

Expose concise MCP resources or prompts for project status, recommended
workflow, backlog item authoring, worker handoff, integration review, and
recovery. Keep the content deterministic and aligned with the public tool
contract.

## Acceptance

- MCP hosts can list and read workflow guidance resources or prompts.
- Guidance references current tool names and required safety gates.
- Documentation explains how hosts should use the resources.
- Tests cover resource or prompt listing and content stability.
- `make check` passes.
