# MCP-086 Recovery tool description polish

## Goal

Make recovery-oriented tools understandable without prior product knowledge, especially `reconcile_project` and doctor/recovery recommendations.

## Implementation Contract

Audit recovery tool descriptions, result summaries, and generated host guidance. Make each recovery tool state what it checks, what it mutates, when to call it, and what a host should do with failures. Keep read-only recovery inspection separate from mutating repair actions.

## Acceptance

- `reconcile_project` documentation names the failure modes it detects.
- Tool descriptions distinguish read-only inspection from mutating repair.
- Recovery `next_action` messages are concrete enough to execute without reading source.
- Tests verify public tool descriptions include the expected recovery hints.
