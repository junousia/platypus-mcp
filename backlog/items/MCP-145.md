# MCP-145 Improve Pi visibility for Platypus tool results with empty stdout

## Goal

Make Pi-rendered Platypus tool calls visibly report useful status, summary, and next action even when the underlying wrapper emits no stdout or only structured content.

## Implementation Contract

Inspect the Pi tool wrapper/result rendering path and add a deterministic fallback display for structured Platypus results that would otherwise appear as an empty or opaque tool response. Keep the rendering compact for routine tools and do not change MCP server schemas.

## Acceptance

- A Platypus tool response with structured status/summary but no stdout renders a visible status line in Pi.
- Mutating tools show enough information to confirm whether the state transition happened.
- Existing compact/expanded rendering behavior for normal tool responses is preserved.
- Pi extension renderer tests cover the fallback.
