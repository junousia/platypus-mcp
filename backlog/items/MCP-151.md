# MCP-151 Improve empty-queue backlog shaping guidance

## Goal

Make the empty-queue path help MCP hosts turn durable roadmap direction into concrete backlog items with less guessing and clearer recovery when product direction is missing.

## Implementation Contract

Use the existing roadmap/workflow direction as input. Improve deterministic guidance and tests for empty backlog/closed queue states; do not add model-generated backlog content inside core MCP tools.

## Acceptance

- Closed/empty queue guidance points hosts to durable direction files and asks for missing product direction rather than inventing details.
- Backlog creation guidance remains deterministic and does not generate pseudo-intelligent item content inside MCP tools.
- Tests cover the improved empty-queue or closed-queue guidance behavior.
