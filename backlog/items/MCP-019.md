# MCP-019 Add workflow integration configuration

## Goal

Add project-level workflow configuration for how completed worker results are
integrated back into the manager workspace.

## Implementation Contract

Extend `platy.yaml` support with a `workflow.integration` section. The first
version must expose typed effective configuration for merge style defaults such
as `merge_commit`, `fast_forward`, and `squash`, preserve unknown config keys,
and use safe defaults when the section is missing.

## Acceptance

- Missing integration config resolves to a safe default merge style.
- Invalid merge styles fail with structured recovery guidance.
- `init_project` writes the default integration config for new projects.
- Existing unknown `platy.yaml` keys are preserved when config is updated.
- `make check` passes.
