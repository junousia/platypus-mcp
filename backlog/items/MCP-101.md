# MCP-101 Clarify direct completion evidence guidance

## Goal

Make agents understand when complete_backlog_item automatic evidence is enough and when record_verification_evidence should be called separately.

## Implementation Contract

Update schema descriptions and host guidance so normal direct work can provide verification_summary directly to complete_backlog_item, while separate record_verification_evidence is reserved for richer, reusable, or pre-completion evidence.

## Acceptance

- complete_backlog_item input descriptions explain automatic evidence behavior.
- Direct workflow docs include a concise evidence rule of thumb.
- No workflow guidance implies record_verification_evidence is mandatory before normal direct completion.
