# MCP-014 Add agent profile configuration tools

## Goal

Let MCP clients inspect and configure manager and worker profiles without
hand-editing hidden runtime files.

## Implementation Contract

Add typed configuration inspection and update tools for named agent profiles,
roles, harness type, executable hints, and capability tags. Keep secrets out of
project files and return recovery guidance when required executables or login
state cannot be verified locally.

## Acceptance

- Agent profiles can be listed with role and capability metadata.
- Profile updates are validated and persisted in a documented project config.
- Secret values are rejected or redacted.
- Tests cover manager, worker, invalid role, and missing executable guidance.
