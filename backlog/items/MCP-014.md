# MCP-014 Remove local agent configuration tools

## Goal

Keep agent selection and creation outside the MCP server. Platypus should expose
project workflow state and durable handoff records, while the MCP host decides
which configured harness or human executor receives the work.

## Implementation Contract

Remove profile configuration/readiness tools and any project-level agent
creation surface. Preserve workflow configuration inspection, but do not persist
manager/worker harness definitions in Platypus project config. Dispatch and
handoff tools must describe the required work without claiming a local worker
was created or verified.

## Acceptance

- No MCP tool configures, creates, or validates local agents.
- Status, doctor, and work queue tools do not warn about missing local agent
  setup.
- Dispatch records externally managed handoff metadata instead of worker
  readiness.
- Tests cover dispatch/status behavior without any configured local agents.
