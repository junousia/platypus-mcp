# MCP-143 Harden release and installation validation

## Goal

Keep crates.io, GitHub release artifacts, npm package contents, platform binary fallback, and bootstrap diagnostics simple enough for fresh installs by expanding local release validation.

## Implementation Contract

Inspect current Makefile, npm validation scripts, package metadata, and release docs. Add local deterministic checks for package contents and binary resolution paths where practical; do not require network publishing or real GitHub release execution.

## Acceptance

- Local validation covers expected npm package contents and platform binary fallback metadata.
- Release/install docs describe the validated fresh-install path accurately.
- Checks avoid network-only dependencies and can run in CI-style local verification.
- `make check` or the relevant package validation targets pass.
