# MCP-075 Integration gate inspection

## Goal

Give hosts a read-only way to see exactly why a task can or cannot be integrated before they call mutating completion or integration tools.

## Implementation Contract

Add an `inspect_integration_gates` MCP tool keyed by `task_id`. It must report task lifecycle, verification policy/evidence, required findings, manager workspace cleanliness, worktree branch readiness, and a concise next action. It must not mutate project files, Git state, or runtime state.

## Acceptance

- `inspect_integration_gates` reports every integration blocker currently enforced by `integrate_worker_result`.
- The response includes structured gates with status, summary, and suggested recovery tool where applicable.
- Tests cover ready, missing verification, unresolved required findings, dirty manager workspace, and non-completed task states.
- Documentation lists the tool in the task/workspace lifecycle.
