# MCP-059 Classify direct scaffold versus Platypus workflow fit

## Goal

Help MCP hosts avoid over-applying the full Platypus backlog workflow to simple greenfield scaffolding requests while still steering sustained work into structured development.

## Implementation Contract

Add a deterministic workflow-fit classifier that receives a user goal and current project context, then recommends direct_scaffold, platypus_workflow, or hybrid. Expose it as an MCP tool with typed schema, host guidance, and tests. The classifier must be conservative, transparent about reasons, and must not execute scaffold commands or bypass safety checks.

## Acceptance

- A simple new app scaffolding goal returns direct_scaffold or hybrid guidance instead of forcing backlog dispatch.
- Goals involving multi-step implementation, existing backlog, safety-critical surfaces, or traceability return platypus_workflow guidance.
- Tool output includes reasons and a concrete next action for the host.
- Host guidance and docs explain when to use direct scaffold first versus full Platypus workflow.
- Tests cover greenfield scaffold, sustained project work, and ambiguous hybrid cases.
