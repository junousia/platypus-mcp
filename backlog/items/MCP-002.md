# MCP-002 Implement findings MCP tools

## Goal

Implement the findings feedback loop tools so agents can persist, list, validate, and disposition implementation findings.

## Implementation Contract

Replace findings stubs with typed storage-backed MCP tools. Findings must include source item/task references, title, summary, status, severity, owner, evidence refs, and timestamps. Validation must fail when source work has unaddressed required findings.

## Acceptance

- `list_findings` returns stored findings with filters and limits.
- `update_finding_disposition` persists status, owner, reason, evidence refs, and metadata.
- `validate_findings` reports unresolved required findings for a source item/task.
- SDK-level MCP tests cover create fixture data, list, update, and validate paths.
- `make check` passes.
