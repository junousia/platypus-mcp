# MCP-060 Dispatch ready work with prepared handoffs

## Goal

Make the normal path for parallel worker execution one safe tool call that dispatches runnable backlog items and prepares assignment handoffs/worktrees for each selected worker task.

## Implementation Contract

Add a typed batch dispatch and handoff tool that can select up to max_tasks runnable backlog items, skip already-active items, optionally filter by worker, prepare worker assignments and bundles by default, and return per-item task/assignment results. dispatch_next_work must also report Git readiness blockers before creating queued tasks. Keep all behavior bounded to the project root and preserve existing single-item tools.

## Acceptance

- dispatch_next_work fails with clear Git readiness guidance when worktree execution cannot proceed.
- New batch tool can dispatch and prepare at least two independent backlog items in one call.
- Batch tool returns per-item task id, assignment id, worktree path, and skipped/failure reasons.
- Already-active backlog items are skipped without preventing later independent items from being dispatched.
- Tests cover batch dispatch, prepared handoffs, active-item skipping, and readiness blocking.
