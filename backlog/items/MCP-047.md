# MCP-047 Migrate evidence findings and reconciliation to ProjectState

## Goal

Move evidence, findings, reconciliation, and workspace metadata reads/writes behind backend-independent ProjectState operations.

## Implementation Contract

Expose domain operations for recording verification evidence, recording and dispositioning findings, reconciling project state, and tracking worktree metadata. Keep backend-specific persistence private.

## Acceptance

- evidence.rs, findings.rs, reconcile.rs, and workspace metadata paths do not import rusqlite outside the backend implementation.
- Reconciliation uses ProjectState snapshots and evidence/finding APIs instead of SQL joins in product logic.
- Existing evidence, findings, reconciliation, and worktree tests still pass.
- Failure and recovery guidance remains structured and backend-neutral.
