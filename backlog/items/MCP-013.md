# MCP-013 Add evidence cache and reconciliation

## Goal

Keep verifiable evidence for task outcomes, findings, and completion decisions
without putting runtime fields back into backlog markdown.

## Implementation Contract

Add typed evidence records for commits, verification commands, file summaries,
worker findings, and manager dispositions. Add reconciliation that compares
backlog closure trailers, task state, findings, and evidence records and
returns actionable gaps.

## Acceptance

- Evidence records are stored with source, kind, summary, and references.
- Reconciliation reports unresolved findings and unverified completed work.
- Git trailer closure is used as the source for backlog item completion.
- Tests cover clean and failing reconciliation snapshots.
