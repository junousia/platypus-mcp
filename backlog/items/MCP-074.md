# MCP-074 Goal planning entrypoint alias and guidance cleanup

## Goal

Make the read-only goal planning entrypoint discoverable under the user-facing `plan_goal_work` name while preserving the existing `classify_goal_workflow` contract.

## Implementation Contract

Expose `plan_goal_work` as a read-only MCP tool alias that returns the same typed response as `classify_goal_workflow`. Update generated host guidance, docs, and tests so prompts do not reference non-existent tools. Keep the deterministic-heuristic wording clear.

## Acceptance

- MCP tool discovery includes `plan_goal_work` and `classify_goal_workflow`.
- `plan_goal_work` calls the same implementation as `classify_goal_workflow`.
- Host guidance and documentation consistently present `plan_goal_work` as the friendly entrypoint.
- Tests verify the alias is advertised and returns the same planning data shape.
