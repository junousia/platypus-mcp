# MCP-040 Installation and client configuration polish

## Goal

Make a fresh user able to install or run the MCP server and configure Codex or
Claude without guessing paths, environment variables, or smoke-test commands.

## Implementation Contract

Document and automate the current best local install path. Add Makefile or
scripted helpers only where they reduce real setup friction. Configuration
snippets must avoid hard-coded developer paths and must explain project-root
binding, stdio transport, and how to smoke test one tool call.

## Acceptance

- Documentation covers local development, cargo install/path-based use, Codex
  MCP config, Claude MCP config, and `PLATYPUS_MCP_ROOT`.
- A user can run one command to verify the binary and one command to smoke test
  `inspect_status` or `inspect_work_queue`.
- Generated or documented config examples do not include repository-specific
  absolute paths except as clearly marked placeholders.
- Makefile help remains categorized and includes any new setup/smoke target.
- `make check` validates the repository after the install docs/helpers change.

## Notes

This should productize the stdio MCP usage before adding streamable HTTP or
packaging automation.
