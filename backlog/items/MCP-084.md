# MCP-084 Completion evidence controls

## Goal

Make automatic evidence creation during `complete_backlog_item` explicit, inspectable, and configurable.

## Implementation Contract

Extend direct completion so hosts can see exactly which evidence records were created and optionally disable automatic evidence when they want to provide explicit evidence records. Preserve the current default traceability behavior.

## Acceptance

- `complete_backlog_item` response lists generated evidence IDs and summaries.
- A typed option can disable automatic evidence generation.
- Disabling automatic evidence does not skip item completion when verification policy allows it.
- Tests cover default evidence generation, disabled generation, and explicit evidence references.
