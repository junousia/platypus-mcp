# MCP-020 Add managed worker result integration

## Goal

Add an MCP tool that safely integrates a completed worker task worktree back
into the manager workspace.

## Implementation Contract

Add `integrate_worker_result` as the canonical integration path. It must require
a clean manager workspace, a completed task, recorded worktree metadata, and
verification evidence by default. It must use the configured merge style and
create a commit containing `Platypus-Closes` and `Platypus-Verification`
trailers.

## Acceptance

- A completed verified task can be integrated into the manager workspace.
- Integration refuses unverified work with actionable recovery guidance.
- Integration refuses a dirty manager workspace before mutating it.
- Merge conflicts fail safely without hiding recovery details.
- Tests cover configured merge styles and conflict/refusal paths.
- `make check` passes.
