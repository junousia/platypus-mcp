# MCP-039 Host-style MCP lifecycle exercise

## Goal

Add an end-to-end exercise that drives Platypus through the MCP contract the
way a real host would, using only local fixtures and fake workers/providers.

## Implementation Contract

The test should start from a temporary project, initialize it, import or create
backlog work, write any required task plan, inspect the queue, dispatch work,
prepare a handoff, simulate worker progress/result, record verification,
integrate or reconcile according to current policy, and draft an external
report. It must not rely on Codex, Claude, GitHub, or network access.

## Acceptance

- The exercise uses the public MCP tool surface rather than private Rust helper
  shortcuts.
- It verifies every important response is structured and includes actionable
  next steps on skipped/failed paths.
- It proves imported external work can flow through local execution to an
  external report draft.
- The fixture is deterministic and can run in normal `make check`.
- Workflow docs mention the exercise as the reference product smoke path.

## Notes

This item is meant to keep the MCP boundary honest as the tool surface grows.
