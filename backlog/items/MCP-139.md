# MCP-139 Finish Pi extension polish and package verification

## Goal

Finish the in-progress Pi extension polish so the Platypus UI is quieter by default, item-selection flows are usable, and package verification covers the expected behavior.

## Implementation Contract

Review the existing uncommitted Pi extension changes, preserve intended UI improvements, add or adjust focused npm harness assertions, and keep the package integration compatible with the existing Pi extension APIs. Do not broaden this into unrelated Rust MCP behavior.

## Acceptance

- Pi footer/status remains hidden when there is no actionable Platypus state and shows only for errors, ready/blocked/active work, or pending integration.
- Pi widget is hidden by default at session start and can still be shown through existing commands.
- Commands that need an item can select from known snapshot items when no explicit argument is provided.
- NPM Pi extension tests cover the changed behavior and pass locally.
