# MCP-009 Add worker adapter boundary

## Goal

Define the stable boundary between the Platypus runner and concrete harnesses
such as Codex and Claude.

## Implementation Contract

Add typed adapter traits and result/event models for worker start, streamed safe
activity, tool requests, final result, structured failure, and findings. Include
a fake adapter for tests. The runner must depend on the trait, not on a concrete
harness.

## Acceptance

- A fake adapter can complete a task through the runner.
- Worker results include summary, changed files, verification status, and
  findings.
- Adapter failures are structured and persisted as task events.
- No Codex- or Claude-specific assumptions leak into runner core.
