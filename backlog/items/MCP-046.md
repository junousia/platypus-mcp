# MCP-046 Migrate guidance and inspection reads to ProjectState

## Goal

Move queue inspection, task inspection, assignment inspection, bundle reads, and event replay onto backend-independent state APIs.

## Implementation Contract

Replace direct SQL reads in guidance and inspection-oriented modules with ProjectState query operations that return domain snapshots. Keep query methods domain-shaped and avoid list-by-table/status leakage in public traits.

## Acceptance

- guidance.rs no longer imports rusqlite or queries database tables directly.
- Inspection tools get task, assignment, event, and bundle data through ProjectState snapshots.
- inspect_work_queue preserves current recommendations for running, prepared, claimed, queued, verification, integration, and empty states.
- Tests cover queue guidance against the ProjectState implementation rather than raw SQL helpers.
