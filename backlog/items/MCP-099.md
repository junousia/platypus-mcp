# MCP-099 Add host-neutral schema discovery hints

## Goal

Reduce harness-specific schema discovery friction by making next-schema hints useful outside Claude ToolSearch.

## Implementation Contract

Extend schema discovery hint output with host-neutral search/query text and a response-level Claude batch selector where applicable. Keep existing claude_toolsearch_selector for compatibility and document that it is Claude-specific.

## Acceptance

- schemas_likely_needed_next entries include host-neutral search text or equivalent host-neutral discovery guidance.
- Queue/session responses expose a combined Claude selector when multiple next schemas are likely useful.
- Docs explicitly state that Claude selectors are host-specific and other hosts should use host-neutral tool names/search terms.
- Tests cover hint serialization for empty_backlog and direct_ready states.
