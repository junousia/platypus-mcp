# MCP-111 Expose compact startup health fields

## Goal

Make compact inspect_session output show that setup was checked without forcing callers to request the full doctor payload.

## Implementation Contract

Extend compact inspect_session data with explicit setup health booleans or short status fields for scaffold, Git, backlog, and workflow configuration. Keep verbose doctor details behind the existing detail mode.

## Acceptance

- Compact inspect_session includes setup health fields such as scaffold, git, backlog, and workflow readiness.
- The fields are derived from existing deterministic checks and do not mutate project state.
- Verbose inspect_session remains available for detailed doctor/status payloads.
- Tests cover healthy, missing scaffold, unborn Git, and empty backlog cases.
