# MCP-149 Avoid post-integration formatting-only cleanup commits

## Goal

Reduce integration workflows that require an extra manager-workspace formatting commit after worker results are integrated.

## Implementation Contract

Review whether worker bundles, completion contracts, or integration gates can require or verify formatting before integration. Prefer guidance and verification enforcement over automatic formatting. Do not run arbitrary formatting commands inside MCP tools.

## Acceptance

- Worker handoff/completion guidance makes formatting verification expectations explicit before integration.
- Integration or review guidance flags formatting-sensitive changes before final manager-workspace integration where practical.
- No arbitrary formatter execution is introduced inside MCP tools.
- Tests or docs cover the expected verification path.
