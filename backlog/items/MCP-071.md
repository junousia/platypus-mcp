# MCP-071 Explicit manual execution handoff mode

## Goal

Provide a safe fallback for external or manually managed workers without bypassing task lifecycle and worktree isolation.

## Implementation Contract

Add an explicit `execution_mode` to dispatch with host-managed execution as the
only persisted worker path. Default behavior must not silently edit the manager
workspace. Dispatch should create the normal task, assignment, worktree, and
handoff bundle, record that execution is externally managed, and guide the host
through `start_worker_task`, `complete_worker_task`, evidence recording, and
integration.

## Acceptance

- `dispatch_ready_work` with `execution_mode=manual_handoff` prepares a
  worktree-backed host handoff without local worker configuration.
- Default dispatch creates host-managed handoff state instead of silently
  degrading to manager-workspace edits.
- Manual handoff assignments clearly record claimant and externally managed execution metadata.
- Evidence and verification associated with a task remain attached to the lifecycle task and are not orphaned.
- `reconcile_project` reports evidence tied to tasks that never reached a valid lifecycle state.
- Tests cover manual handoff dispatch, default host-managed behavior, lifecycle
  recording, and reconciliation of orphaned evidence.
