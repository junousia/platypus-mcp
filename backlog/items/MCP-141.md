# MCP-141 Improve worker handoff retry and recovery coverage

## Goal

Make failed handoffs, stale worktrees, retries, and result integration paths boringly recoverable across host restarts by adding focused coverage and tightening guidance where gaps are found.

## Implementation Contract

Start with tests around existing behavior for interrupted handoff, stale or obstructed worktree paths, retry behavior, and integration-gate guidance. Only change product behavior when a test exposes ambiguous or unsafe recovery output.

## Acceptance

- Tests cover at least one failed or interrupted handoff path and the safe retry/recovery guidance returned to the host.
- Stale or obstructed worktree scenarios remain inspectable and do not require source inspection to recover.
- Any changed recovery messages include concrete next actions.
- `make check` passes.
