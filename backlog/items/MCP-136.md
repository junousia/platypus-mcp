# MCP-136 Add Pi guided workflow documentation and examples

## Goal

Document the Pi-guided Platypus workflow as the showcase for structured, sustainable vibe coding.

## Implementation Contract

Add concise examples for first setup, project direction capture, engineering standards, story review, implementation plan review, product steering, and post-implementation review. The docs should show how Pi helps the agent and user make decisions while the MCP server remains deterministic and host-neutral.

Prefer one coherent end-to-end example over disconnected command references.

## Acceptance

- README summarizes the Pi-guided workflow and links to the full example.
- Workflow docs include an end-to-end project setup and implementation story.
- Tool docs identify which MCP tools support each Pi workflow phase.
- Install docs explain how to start the Pi showcase path and how to recover if Pi cannot load Platypus.
- Documentation clearly states that project direction and standards are durable repo artifacts, not hidden chat state.
