# MCP-005 Add task lifecycle claiming

## Goal

Make dispatched work claimable and inspectable by a future local runner without
starting worker processes inside MCP tool calls.

## Implementation Contract

Add durable task lifecycle fields and APIs for queued, claimed, running, and
terminal task states. Enforce one active task per backlog item, provide an
atomic claim operation, and expose MCP tools for inspecting a task and claiming
the next queued task. Do not run shell commands or worker harnesses.

## Acceptance

- Dispatch cannot create duplicate active tasks for the same backlog item.
- A queued task can be atomically claimed by worker or claimant.
- Claiming writes a task event and updates task lifecycle fields.
- `inspect_task` returns the persisted task record.
- `make check` passes.
