# MCP-051 Ignore closed-item active tasks in safe-action guidance

## Goal

Make next_safe_action reconcile active task state with Git closure trailers so closed backlog items do not keep the project stuck on obsolete handoff guidance.

## Implementation Contract

When inspecting queued, claimed, prepared, or running work, safe-action guidance must skip tasks whose source_item_id is closed by Platypus Git trailers. The behavior should preserve normal active-task guidance for open items and should not mutate task history implicitly.

## Acceptance

- next_safe_action skips queued or claimed tasks whose source backlog item is closed by Git trailers.
- next_safe_action still prioritizes active tasks for open backlog items before dispatching new work.
- A regression test covers a closed-item queued task plus a later runnable item.
- Task events and reconciliation remain read-only for skipped stale tasks.
