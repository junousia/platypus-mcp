# MCP-051 Ignore closed-item active tasks in queue guidance

## Goal

Make inspect_work_queue reconcile active task state with Git closure trailers so closed backlog items do not keep the project stuck on obsolete handoff guidance.

## Implementation Contract

When inspecting queued, claimed, prepared, or running work, queue guidance must skip tasks whose source_item_id is closed by Platypus Git trailers. The behavior should preserve normal active-task guidance for open items and should not mutate task history implicitly.

## Acceptance

- inspect_work_queue skips queued or claimed tasks whose source backlog item is closed by Git trailers.
- inspect_work_queue still prioritizes active tasks for open backlog items before dispatching new work.
- A regression test covers a closed-item queued task plus a later runnable item.
- Task events and reconciliation remain read-only for skipped stale tasks.
