# MCP-121 Add Linux arm64 and macOS Intel npm binaries

## Goal

Publish package-local `platypus-mcp` binaries for `linux-arm64` and `darwin-x64` in addition to the existing `linux-x64` and `darwin-arm64` npm release binaries.

## Implementation Contract

Extend the GitHub release package matrix and required npm release platform validation so the `platypus-pi` package includes four supported native binaries:

- `linux-x64`
- `linux-arm64`
- `darwin-x64`
- `darwin-arm64`

Use native hosted runners for the new platforms where available, keep the existing package-local `vendor/<platform>/platypus-mcp` layout, and update documentation and developer command help to describe the full required platform set.

## Acceptance

- Publish workflow builds and uploads `linux-arm64` binary artifacts.
- Publish workflow builds and uploads `darwin-x64` binary artifacts.
- Final npm publish job requires all four supported platforms before publishing.
- Local strict npm validation can validate all four platform paths.
- README, install docs, and Makefile help describe the complete supported npm binary platform set.
