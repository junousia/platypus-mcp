# MCP-018 Implement harness execution adapters

## Goal

Turn the Codex and Claude adapter skeletons into bounded execution paths that
can run task bundles through existing installed harnesses.

## Implementation Contract

Keep execution opt-in and bounded. Validate executable availability, pass a task
brief and workspace root, capture safe event summaries, preserve fail-closed
behavior for unsupported modes, and avoid embedding provider credentials or
client-specific session assumptions in the MCP server.

## Acceptance

- Codex and Claude adapters can run through deterministic fake process fixtures
  in tests.
- Live execution remains disabled unless explicitly configured.
- Worker events are persisted and replayable for start, progress, result, and
  failure cases.
- Failures are structured and do not leave task state ambiguous.
- `make check` passes.
