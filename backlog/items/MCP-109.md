# MCP-109 Simplify quick backlog tracking for small direct work

## Goal

Provide a low-friction way to track one small direct item without making the caller fill the full strict backlog model.

## Implementation Contract

Refine quick_create_backlog_item or add a clearly named quick tracking path that requires only deterministic inputs such as title and type, applies safe defaults, and explains when to use the full create_backlog_items path. Avoid fake-intelligent generation of contracts or acceptance criteria.

## Acceptance

- A caller can create one valid direct tracking item with minimal deterministic fields.
- The quick path does not invent misleading implementation_contract text.
- The response explains which defaults were applied and when to switch to create_backlog_items.
- Tests cover minimal input, invalid type, default epic, and validation output.
