# MCP-113 Clarify lightweight direct completion and auto evidence

## Goal

Make complete_backlog_item easier to use for small direct work while keeping evidence and verification semantics explicit.

## Implementation Contract

Review complete_backlog_item required fields and response guidance. Improve the direct-ready path so agents understand the minimum acceptable completion payload, when changed_files or verification details are expected, how auto evidence is created, and how explicit evidence_refs interact with auto evidence.

## Acceptance

- Tool schema and docs explain the minimum direct completion payload and when changed_files can be empty.
- Auto-generated evidence behavior is prominent in direct-ready guidance and complete_backlog_item output.
- Explicit evidence_refs behavior is documented, including whether auto evidence is suppressed or combined.
- Tests cover trivial non-file work, file-changing work, explicit evidence refs, and unverified completion recovery guidance.
