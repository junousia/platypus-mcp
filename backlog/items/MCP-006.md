# MCP-006 Add workspace manager

## Goal

Create and inspect isolated task workspaces so claimed tasks can be prepared for
external harness execution without embedding worker logic in MCP tool calls.

## Implementation Contract

Add deterministic workspace tools around Git worktrees under
`.platy/worktrees/<task_id>`. Use fixed Git commands only, reject unborn or
non-Git repositories, enforce project-root containment, persist workspace
metadata on the task record, and emit task events for workspace creation. Do
not run arbitrary shell commands.

## Acceptance

- Workspace creation fails safely when `HEAD` is not a commit.
- Workspace paths are contained under `.platy/worktrees`.
- Workspace branch, path, and base ref are persisted on the task.
- Workspace creation emits a task event.
- Tests cover success and failure paths without invoking a worker harness.
