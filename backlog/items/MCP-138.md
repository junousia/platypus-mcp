# MCP-138 Add Pi selection dialogs for Platypus item workflows

## Goal

Use Pi TUI selection widgets when Platypus extension commands need a user to choose among multiple backlog items or workflow actions.

## Implementation Contract

Add focused SelectList-based overlays for item selection in relevant Pi extension commands while preserving fast single-item defaults, shortcut behavior, and existing command names. Keep behavior bounded to current extension state and avoid model-owned planning decisions.

## Acceptance

- /platy-start selects directly when one ready item exists and opens a selector when multiple ready items exist.
- Review commands can select a backlog item from known ready/blocked snapshot items when no explicit command argument is provided.
- The selector uses Pi TUI built-in selection components and has cancel behavior.
- Existing Pi extension tests pass or are updated for the new helper behavior.
