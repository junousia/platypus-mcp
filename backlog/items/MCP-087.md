# MCP-087 Host schema preload cold-start polish

## Goal

Reduce the apparent cold-start tax for hosts with deferred tool schemas, especially Claude Code, without depending on non-standard host behavior.

## Implementation Contract

Refine preload guidance into smaller named tool groups, ensure generated host files tell agents exactly which group to load for startup, planning, direct execution, worker handoff, and recovery, and update feedback scripts to exercise the guidance. The MCP server must remain usable when the host ignores preload guidance.

## Acceptance

- Host guidance exposes concise startup, planning, direct execution, worker handoff, and recovery tool groups.
- Generated host files tell deferred-schema hosts which group to load before each workflow phase.
- Feedback scripts prompt harnesses to evaluate whether preload guidance reduced cold-start friction.
- Tests verify the guidance text contains the named groups and remains host-neutral.
