# MCP-049 Enforce SQL isolation outside backend modules

## Goal

Add a guard that prevents rusqlite and direct SQL operations from leaking back into product and MCP tool modules.

## Implementation Contract

Add a test or developer check that scans source files and fails when rusqlite, SQL query helpers, or raw database connections appear outside approved backend implementation modules. Document the allowed backend-only locations.

## Acceptance

- A repeatable check fails if rusqlite is imported outside the SQLite backend implementation and approved migration/probe internals.
- The check is part of make check or an explicitly documented verification target.
- The allowlist is narrow and documented in docs/storage.md.
- All existing tests and make check pass with the guard enabled.
