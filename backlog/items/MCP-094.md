# MCP-094 Clean feedback harness and guidance naming drift

## Goal

Remove stale feedback harness inputs and make host guidance reference only available, correctly scoped tools.

## Implementation Contract

Remove deprecated require_task_plan from smoke calls, publish a preferred tool naming and alias map, eliminate references to unavailable tools such as draft_task_plan from active guidance, and clarify that inspect_integration_gates is for completed worker task or worktree integration only while direct manager-workspace work completes through complete_backlog_item.

## Acceptance

- Feedback smoke calls and make smoke-queue no longer pass deprecated require_task_plan and no longer emit the compatibility warning.
- Generated guidance, host guidance resources, and docs reference only tools exposed by the server or explicitly documented compatibility aliases.
- A tool naming map documents preferred host-facing names and compatibility aliases for worker lifecycle tools.
- inspect_integration_gates schema, tool description, docs, and missing-task recovery make clear that backlog item ids and direct-edit work should use inspect_item, inspect_work_queue, or complete_backlog_item instead.
- Tests cover guidance/tool-name drift and integration-gate recovery guidance.
