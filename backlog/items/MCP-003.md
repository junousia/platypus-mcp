# MCP-003 Implement task event inspection tools

## Goal

Implement task event storage and inspection so worker activity can be replayed through MCP.

## Implementation Contract

Replace `inspect_task_events` stub with storage-backed event listing. Define typed task event records and bounded replay by task id and limit. Keep event insertion as internal API for later dispatch work.

## Acceptance

- Task events can be inserted through Rust API and listed through MCP.
- `inspect_task_events` handles unknown task ids with structured skipped/failed result.
- Output is bounded and ordered by event sequence/time.
- SDK-level MCP tests cover event replay.
- `make check` passes.
