# MCP-085 Host workflow guidance state sync

## Goal

Keep generated host guidance, workflow docs, and actual tool response states aligned so hosts do not have to infer missing lifecycle rows.

## Implementation Contract

Update host guidance resources, generated AGENTS/CLAUDE files, and public docs to describe the exact direct and worker state machine. Include whether `inspect_session` satisfies detector steps, the direct prepared follow-up, the minimum viable direct-edit loop, and the traceability tradeoff for tiny tasks.

## Acceptance

- Generated guidance has rows for every state emitted by queue, prepare, finish, and integration tools.
- Guidance states when `inspect_session` can replace separate startup detector calls.
- The minimum viable direct-edit loop is documented without weakening the long-term tracked workflow.
- Tests verify generated guidance mentions the critical direct and worker states.
