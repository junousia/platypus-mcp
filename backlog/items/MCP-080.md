# MCP-080 Compact work queue status

## Goal

Make quick queue triage possible without forcing hosts to parse the full `inspect_work_queue` inventory payload.

## Implementation Contract

Add a compact queue inspection surface, either as `inspect_work_queue` output mode or a dedicated `quick_status` tool, that returns counts, top ready items, top blocked items, active tasks, and short queue-state descriptions. Keep the existing full queue output stable for detailed control flows.

## Acceptance

- A compact call returns runnable, blocked, active, pending integration, closed, and total counts.
- The response includes the top ready item IDs and titles plus one-line queue-state descriptions.
- The full `inspect_work_queue` response remains backward compatible.
- Documentation explains when to use compact status, full queue inspection, and `list_backlog`.
