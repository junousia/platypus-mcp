# MCP-114 Trim generated host guidance and schema preload claims

## Goal

Reduce duplicated generated guidance while making host schema-loading limits explicit for Codex, Claude, OpenCode, and Pi.

## Implementation Contract

Shorten generated CLAUDE.md and related host guidance to the critical startup rules and exact workflow table, then point to MCP resources for full detail. Make clear that preload resources provide hints/selectors unless a host actually supports automatic schema preloading.

## Acceptance

- Generated CLAUDE.md is materially shorter while retaining critical rules, startup command, and state table.
- Guidance states that inspect_session subsumes doctor_snapshot at startup except for explicit recovery or detailed diagnostics.
- Codex/Claude/OpenCode/Pi schema preload wording distinguishes advisory search hints from automatic schema registration.
- Tests cover generated AGENTS.md and CLAUDE.md content so the critical rules are not dropped.
