# MCP-016 Add worktree diff and cleanup tools

## Goal

Let MCP clients inspect and safely clean task worktrees without shelling out or
guessing project paths.

## Implementation Contract

Add typed `worktree_diff` and `worktree_cleanup` tools. Diff output must be
bounded and rooted in the recorded task worktree. Cleanup must refuse dirty or
unknown worktrees unless explicitly forced, remove the Git worktree through safe
Git commands, and update persisted task workspace metadata or events with an
audit-friendly result.

## Acceptance

- `worktree_diff` returns a bounded summary and file list for a recorded task
  worktree.
- `worktree_cleanup` removes a clean recorded worktree and records a task event.
- Dirty worktrees are refused with recovery guidance unless a force flag is
  explicitly provided.
- Path traversal and unrecorded task ids remain blocked.
- `make check` passes.
