# MCP-053 Add layered harness steering files

## Goal

Make initialized Platypus projects transparently steer supported coding harnesses toward the spec-driven MCP workflow.

## Implementation Contract

Extend init_project so generated repo-local guidance uses one shared spec-driven text for generic agent instructions and Claude Code instructions. Keep MCP as the stable contract and do not add unverified host-specific files for harnesses without a known local instruction mechanism. Update docs to explain that bootstrap wires MCP while init_project installs the transparent repo-local steering layer.

## Acceptance

- init_project creates CLAUDE.md alongside AGENTS.md without overwriting existing files by default.
- AGENTS.md and CLAUDE.md use the same canonical spec-driven workflow guidance.
- Documentation explains the layered steering model and its host-specific limits.
- Tests cover scaffold creation and preservation behavior for the new guidance file.

## Notes

Created from the plan for transparent harness behavior: MCP instructions/resources first, repo-local guidance files for supported hosts, no speculative host files.
