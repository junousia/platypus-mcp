# MCP-115 Add minimal direct-work examples

## Goal

Give agents a short concrete example for a minimal direct documentation or small-code item from creation through completion.

## Implementation Contract

Add one concise host-neutral example showing create_backlog_items, inspect_work_queue, manager-workspace edit and verification, then complete_backlog_item with inline evidence. Keep it explicit that this path is for sustained tracked work, not disposable one-shot tasks.

## Acceptance

- Docs include a minimal direct item example with concrete tool names and fields.
- The example shows inline auto evidence and the expected completion response shape.
- The example explains when to switch from minimal direct work to richer task planning or worker handoff.
- Generated host guidance points to the example without duplicating it in full.
