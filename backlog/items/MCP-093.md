# MCP-093 Polish evidence and recovery guidance edge cases

## Goal

Resolve lower-severity feedback around evidence kind examples, epic defaults, and when reconcile_project is optional versus required.

## Implementation Contract

Improve schema descriptions, generated guidance, and recovery wording so agents understand evidence kind differences, the general epic default, and when reconcile_project should be used after direct completion.

## Acceptance

- Evidence kind documentation includes concise examples that distinguish note, file_summary, verification, commit, and finding-related evidence.
- Backlog creation guidance documents the general epic default and warns or guides when multiple epics make omission risky.
- complete_backlog_item and guidance distinguish optional reconciliation from required recovery after unclear or failed state transitions.
- Tests or generated-doc assertions cover the updated guidance text.
