# MCP-007 Add task bundle generation

## Goal

Generate a deterministic task brief from a backlog item, task record, workspace,
owned surfaces, acceptance criteria, and verification guidance.

## Implementation Contract

Add a typed bundle generator that reads the declarative backlog item and task
state, produces a bounded structured brief, and stores or returns enough data
for worker adapters to run consistently. The bundle must avoid hidden runtime
state in backlog markdown.

## Acceptance

- Bundle generation includes goal, contract, acceptance, dependencies, owned
  surfaces, task id, workspace path, and verification guidance.
- Missing backlog or workspace data returns structured recovery guidance.
- Output is bounded and deterministic for the same project state.
- Tests cover valid, missing-task, and missing-workspace cases.
