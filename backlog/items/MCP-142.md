# MCP-142 Improve goal-to-backlog and task-plan ergonomics

## Goal

Reduce host guesswork when turning product direction into backlog items and task plans by improving guidance, response hints, and documentation around tranche shaping.

## Implementation Contract

Review current create_backlog_items, write_task_plan, queue/session guidance, and workflow docs. Add deterministic guidance or response fields only where they clarify the next host action; do not add pseudo-intelligent planning tools that hide model judgment inside the server.

## Acceptance

- Guidance clearly explains how to create a small reviewed tranche when the queue is empty.
- Backlog creation and task-plan responses point to the correct next inspection/planning action without stale assumptions.
- Docs include a concise example of turning product direction into backlog items and task plans.
- Existing backlog validation and task-plan tests pass.
