# MCP-123 Make Pi bootstrap a first-class setup path

## Goal

Make `platypus-mcp bootstrap pi` the preferred first-run path for using Platypus inside Pi, including project initialization and host configuration.

## Implementation Contract

Extend the Pi bootstrap behavior beyond the shared `.mcp.json` adapter path. The command should configure Pi in the shape Pi actually consumes, support `--init-project`, and provide `--check` output that tells the user whether Pi can load the Platypus extension, resolve the MCP binary, and see the initialized project guidance.

Do not make Pi bootstrap depend on the parked Bazel work. Keep Cargo-based development and released npm package behavior working.

## Acceptance

- `platypus-mcp bootstrap pi --root <project> --init-project` creates or updates the Pi-local configuration and initializes Platypus project files.
- `platypus-mcp bootstrap pi --check --root <project>` reports Pi configuration, project scaffold readiness, and binary resolution readiness with actionable recovery guidance.
- The bootstrap output distinguishes host configuration from project initialization.
- Tests cover dry-run, apply, check, existing config preservation, and force replacement behavior.
- README and install docs show the Pi-first setup path.
