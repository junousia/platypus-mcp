# MCP-095 Make direct-edit happy path explicit

## Goal

Make the minimum direct-edit workflow visible in queue and session output so hosts know prepare_work is optional for direct_ready work with no planning gate.

## Implementation Contract

Keep prepare_work as the compatible recommended guidance tool, but add an explicit machine-readable signal such as prepare_work_optional for direct_ready items where execution_path is direct_edit and planning_gate is none. Update reason text, execution guidance, generated project guidance, and docs to state that hosts may edit the manager workspace, verify, and call complete_backlog_item directly for tiny direct work.

## Acceptance

- inspect_work_queue direct_ready items expose a typed signal that prepare_work is optional for direct edit with no planning gate.
- inspect_session surfaces the same direct-edit shortcut through its queue snapshot or reason text.
- prepare_work remains available and recommended for hosts that want response-local guidance, but docs no longer imply it is mandatory for trivial direct work.
- complete_backlog_item remains the durable transition for direct work and works without a prepare marker.
- Tests cover queue output, session output, generated guidance, and direct completion without prepare_work.
