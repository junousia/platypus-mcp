# MCP-057 Expose human-friendly backlog schema guidance

## Goal

Make valid backlog item values and required create_backlog_item fields obvious to MCP hosts and users without requiring source inspection.

## Implementation Contract

Improve schema guidance for backlog authoring by returning precise validation errors for create_backlog_item, documenting valid priority/type values and required fields, and exposing the same guidance through host-facing docs/resources. Keep the existing strict schema and defaults intact.

## Acceptance

- Invalid priority errors include the rejected value and accepted values P0, P1, P2.
- Invalid type errors include the rejected value and accepted backlog types.
- Missing required create_backlog_item fields report each missing field in a host-readable way.
- Documentation and host guidance include a concise backlog schema quick reference.
- Tests cover the improved errors.

## Notes

Created from feedback that priority enum and create_backlog_item required fields were opaque during initial project scaffolding.
