# MCP-048 Add memory ProjectState backend and contract tests

## Goal

Add an implementation-independent contract test suite by running ProjectState behavior against both SQLite and an in-memory backend.

## Implementation Contract

Implement a deterministic MemoryProjectState for tests and add reusable backend contract tests that verify lifecycle, events, approvals, leases, evidence, findings, and reconciliation behavior without depending on SQL.

## Acceptance

- MemoryProjectState implements the same ProjectState trait used by SQLite.
- The same contract tests run against SQLite and memory backends.
- Contract tests cover atomic lifecycle, event ordering, lease conflict, approval recovery, evidence/findings, and reconciliation.
- The memory backend is clearly documented as test/support infrastructure, not production durable storage.
