# MCP-073 Host tool preload guidance

## Goal

Reduce interactive friction from deferred tool schema loading without assuming every MCP host supports the same preload mechanism.

## Implementation Contract

Expose host-facing guidance for the common planning and execution tool groups through resources, prompts, generated host files, and documentation. The server should not depend on client-specific hidden context behavior, but initialized projects should clearly tell Claude, Codex, opencode, and similar hosts which Platypus tools to load at session start.

## Acceptance

- Host guidance includes a concise common startup tool group for planning sessions.
- Host guidance includes a concise common startup tool group for execution sessions.
- Generated `AGENTS.md` and `CLAUDE.md` mention when and how to load the common tool groups.
- Documentation explains that tool preloading is host-specific and optional.
- The guidance avoids requiring sampling or non-standard host behavior.
- Tests verify generated host guidance contains the expected tool groups.
