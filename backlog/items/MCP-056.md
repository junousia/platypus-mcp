# MCP-056 Unify host bootstrap with project initialization

## Goal

Let a fresh Platypus setup configure the MCP host and install repo-local project guidance, including AGENTS.md, through one explicit bootstrap option.

## Implementation Contract

Add a bootstrap option that runs init_project for the selected project root after host configuration is applied. The option must be safe for existing projects, preserve files by default, work with --root and explicit --config paths, and make dry-run/check behavior clear. Documentation should present this as the preferred fresh-project onboarding path while keeping plain host-only bootstrap available.

## Acceptance

- bootstrap <host> exposes an option to initialize project scaffold and guidance files including AGENTS.md.
- The option creates AGENTS.md, CLAUDE.md, WORKFLOW.md, platy.yaml, and backlog scaffold in the target root without overwriting existing files by default.
- Dry-run and check modes do not write project files.
- Bootstrap output makes clear whether project initialization was planned, completed, skipped, or not requested.
- Docs show the fresh-project bootstrap command and explain the split between host config and project guidance.

## Notes

Created from user feedback that onboarding/bootstrap did not leave AGENTS.md in the project, even though init_project does.
