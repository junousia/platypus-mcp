# MCP-091 Improve harness-specific startup and schema preload guidance

## Goal

Make the generated host guidance describe the exact startup path and harness-specific schema discovery behavior observed in feedback runs.

## Implementation Contract

Update tool-preload and generated host guidance so inspect_session is framed as the primary startup call, direct-work quick path is explicit, aliases/deprecations are visible, and Claude Code gets precise ToolSearch select:mcp__platypus__... instructions.

## Acceptance

- Generated AGENTS.md and CLAUDE.md frame inspect_session as the default startup call.
- Tool preload guidance includes a direct work quick path from inspect_session through complete_backlog_item.
- Claude Code guidance documents ToolSearch select:mcp__platypus__<tool> usage and prefix requirements.
- Guidance clearly marks deprecated inputs and alias expectations so agents do not search for stale tools.
- Tests cover generated guidance content.
