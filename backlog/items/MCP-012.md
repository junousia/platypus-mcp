# MCP-012 Add approval and event replay tools

## Goal

Expose durable supervision state for tools and worker activity through MCP so
clients can attach, inspect, approve, deny, and replay without client-specific
gateway behavior.

## Implementation Contract

Add approval listing and response tools plus bounded event replay for project,
task, worker, and approval events. Approvals must fail closed, preserve audit
metadata, and emit events for both requests and responses.

## Acceptance

- Pending approvals can be listed and responded to with typed tools.
- Event replay returns bounded, ordered, typed events.
- Approval responses are durable and auditable.
- Tests cover approve, deny, missing approval, and replay filters.
