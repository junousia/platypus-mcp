# MCP-148 Improve worker owned-surface validation and recovery guidance

## Goal

Make worker changed-file validation easier to recover when implementation legitimately touches a nearby module not listed in the selected task bundle owned surfaces.

## Implementation Contract

Review how task bundle owned surfaces are selected from task plans and how finish_work validates changed files. Do not weaken safety broadly; instead improve task-plan guidance, validation messages, or recovery tooling so the host can update the plan/item or split the work without manual database edits.

## Acceptance

- Unowned changed-file failures explain whether to update the task plan, split work, or discard the out-of-scope change.
- The selected task bundle surfaces are traceable to the task plan and item surfaces.
- Tests cover a changed file outside selected task surfaces and assert actionable recovery guidance.
- `make check` passes.
