# MCP-100 Add compact direct completion output

## Goal

Make complete_backlog_item easy to consume in normal direct-edit flows without dumping the full diagnostic payload every time.

## Implementation Contract

Add an explicit detail/verbose control to complete_backlog_item. Default output should remain structured and sufficient for normal use while verbose mode preserves the current full diagnostic state for debugging and recovery.

## Acceptance

- complete_backlog_item supports a documented compact/default response mode and a verbose response mode.
- Compact completion output includes item id, closure state, evidence refs, queue state, and next ready item when present.
- Verbose mode preserves existing detailed data needed by current tests and debugging flows.
- Tests cover compact and verbose completion behavior.
