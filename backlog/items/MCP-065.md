# MCP-065 First-class epic management tools

## Goal

Allow MCP hosts to create and inspect backlog epics without manually writing epic markdown.

## Implementation Contract

Add a mutating `create_epic` tool and a read-only `list_epics` tool. `create_epic` should write `backlog/epics/<id>.md` using strict typed input, defaults for status and priority, path containment checks, duplicate protection, and immediate validation. `list_epics` should return existing epic IDs and display metadata sorted by ID.

## Acceptance

- `create_epic` creates a valid epic file with fields for id, title, status, priority, and area.
- `create_epic` rejects invalid IDs, duplicate epics, path escapes, and invalid enum values with actionable recovery guidance.
- `list_epics` returns existing epics with id, title, status, priority, area, and path.
- Unknown-epic guidance from backlog item creation can refer to `create_epic` and `list_epics`.
- Tool schemas include descriptions, enum values, and examples.
- Tests cover successful creation, duplicate rejection, invalid input, and listing.
