# MCP-137 Make Pi extension UI less intrusive

## Goal

Make the Platypus Pi extension quiet by default while retaining on-demand dashboard and workflow commands.

## Implementation Contract

Default the backlog widget to hidden, clear idle footer status instead of showing persistent idle text, and render compact Platypus tool results by default while keeping expanded dashboards for explicit inspect/doctor/status commands. Preserve existing commands and shortcuts.

## Acceptance

- The Pi extension no longer shows the backlog widget by default on startup.
- Idle or closed Platypus queue state does not occupy footer status space.
- Platypus tool result rendering is compact for routine tools and expanded for explicit inspection/diagnostic tools.
- Existing /platy-show, /platy-hide, and ctrl+shift+b widget controls continue to work.
- Relevant Pi extension tests are updated or existing tests pass.
