# MCP-092 Expose explicit queue states and evidence visibility

## Goal

Make queue inspection more uniformly machine-readable by exposing empty backlog state and evidence visibility for closed items.

## Implementation Contract

Extend queue/status data so empty backlogs have an explicit state, and closed item summaries can show whether evidence exists without requiring a separate evidence lookup for basic completeness checks.

## Acceptance

- inspect_work_queue or related queue data includes an explicit empty_backlog state when no backlog items exist.
- Closed item summaries expose evidence presence and count when available without dumping full evidence records.
- inspect_queue_status remains compact while reflecting the new state/visibility fields.
- Tests cover empty backlog output and closed item evidence counts.
