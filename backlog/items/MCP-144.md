# MCP-144 Define external system adapter boundary

## Goal

Prepare for Linear, Jira, GitLab, and plugin-backed sources by documenting or lightly scaffolding a provider-neutral external adapter boundary before implementing provider clients.

## Implementation Contract

Focus on boundary shape and safety rules: local snapshots, approved report dispatch, provider-neutral payloads, and explicit host/plugin responsibility for network calls. Avoid adding real provider network clients in this item.

## Acceptance

- Docs describe how external intake snapshots and approved report dispatch map to a provider-neutral adapter boundary.
- Boundary guidance names what belongs in Platypus MCP versus host/plugin provider code.
- No network clients or provider credentials are introduced.
- Existing integration/report tests continue to pass.
