# MCP-067 Backlog dependency graph inspection

## Goal

Make dependency order and blockers visible without requiring callers to inspect individual markdown files.

## Implementation Contract

Add a read-only `inspect_dependency_graph` tool that reads backlog items, derives open and closed state from Git trailers, and returns a bounded dependency graph. The tool should support an optional focus item, include or exclude closed items, detect cycles, and report missing dependency references.

## Acceptance

- The response includes nodes, edges, roots, leaves, topological order, runnable nodes, closed nodes, and blocked nodes.
- Missing dependency references are reported with the item that references them.
- Cycles are detected and returned as structured validation failures.
- Optional focus item output includes only the relevant dependency neighborhood.
- Output is bounded by a documented limit and reports truncation when needed.
- Tests cover a linear chain, independent roots, closed dependencies, missing dependencies, cycle detection, and focused output.
