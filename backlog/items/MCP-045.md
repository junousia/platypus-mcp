# MCP-045 Migrate task and assignment lifecycle to ProjectState

## Goal

Route dispatch, task claim, worker assignment, worker event, and worker completion through ProjectState domain operations.

## Implementation Contract

Move lifecycle invariants behind ProjectState so MCP tools no longer assemble task and assignment state changes from raw SQL or SQL-shaped repositories. Preserve atomicity for claim plus assignment and start/event/complete transitions.

## Acceptance

- Dispatch, prepare assignment, start execution, record worker event, and complete execution call ProjectState methods.
- No lifecycle MCP tool outside the SQLite backend imports rusqlite or accepts raw database connections.
- Existing stdio lifecycle tests pass unchanged or with only expected helper updates.
- A contract test proves duplicate active tasks and duplicate active assignments fail safely through ProjectState.
