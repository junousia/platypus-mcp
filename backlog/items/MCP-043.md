# MCP-043 Introduce ProjectState trait and command types

## Goal

Add a backend-independent ProjectState trait with domain command and result types for Platypus runtime state.

## Implementation Contract

Create a new state module that exposes domain-shaped operations, not SQL-like repositories. The trait should cover lifecycle, inspection, approvals, evidence, findings, and replay at a high level while keeping concrete backend choices private.

## Acceptance

- A new state module defines ProjectState and command/result structs with no rusqlite or SQL terminology in the public API.
- The trait groups operations by Platypus domain behavior rather than table CRUD.
- The API documents which methods are atomic by contract.
- Existing code still compiles and make check passes without changing runtime behavior.
