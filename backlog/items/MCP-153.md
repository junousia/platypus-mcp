# MCP-153 Document provider-neutral external adapter contract

## Goal

Turn the roadmap's external adapter direction into a concrete provider-neutral contract for future Linear, Jira, GitLab, and plugin-backed imports/reporting.

## Implementation Contract

Clarify schemas, approval boundaries, and safe/unsafe provider operations using existing external intake/report concepts. Keep provider clients outside core MCP and avoid adding provider network calls.

## Acceptance

- Docs describe the provider-neutral external adapter contract and approval boundaries.
- Guidance distinguishes import snapshots, approved reporting, mirror/sync modes, and provider-client ownership.
- Core MCP remains provider-neutral with no new provider API dependency.
