# MCP-017 Add worker guidance mailbox

## Goal

Make `send_worker_guidance` persist user or manager steering messages for active
worker tasks instead of returning an unsupported placeholder.

## Implementation Contract

Store guidance as durable task-scoped records or events with author, summary,
message body, and timestamp. Keep the first implementation deterministic: it
does not need live harness interruption, but it must make guidance visible to
runners, event replay, and task inspection surfaces.

## Acceptance

- `send_worker_guidance` accepts guidance for known active tasks and returns a
  structured persisted record.
- Guidance is rejected for unknown or terminal tasks with recovery guidance.
- Task event replay includes guidance in chronological order.
- Tests cover accepted guidance, unknown task rejection, and terminal task
  rejection.
- `make check` passes.
