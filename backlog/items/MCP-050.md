# MCP-050 Recover failed worker handoff without wedging task lifecycle

## Goal

Make failed prepare_worker_handoff attempts recoverable so a task is not left claimed without an assignment or worktree.

## Implementation Contract

When branch or worktree creation fails after claim, the lifecycle must either roll back the claim or persist a structured failed handoff state with a clear retry/release recovery path. Retrying should not require manually knowing internal refs.

## Acceptance

- A failed prepare_worker_handoff does not leave next_safe_action stuck without recovery guidance.
- Retried handoff after a transient branch/worktree failure either succeeds or returns an existing inspectable failure state.
- The task event log records the failed handoff with safe error details.
- A stdio protocol test covers failure followed by recovery or explicit release.
