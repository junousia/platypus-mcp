# MCP-126 Streamline Pi happy-path workflow commands

## Goal

Make the normal Pi experience flow from idea to tracked work to completion with minimal manual command knowledge.

## Implementation Contract

Refine Pi commands, shortcuts, autocomplete, and prompt injection around the happy path:

- inspect session and queue
- create backlog items when the queue is empty
- start the next direct-ready item
- complete work with evidence
- show the next action

The extension should guide the host agent without hardcoding fake planning decisions. It should surface options and current state, then let the agent and user decide what to do.

## Acceptance

- Pi commands cover refresh/status, show ready work, start next item, complete current item, show/hide the widget, and recovery guidance.
- Prompt injection includes the current Platypus queue snapshot only when it is relevant and avoids stale repeated guidance.
- Backlog IDs autocomplete from the current snapshot.
- The start/complete prompts name the exact tools the agent should use and the minimum required fields.
- Documentation describes the expected user flow without requiring the user to know every underlying MCP tool.
