# MCP-102 Plan direct work claim and changed-file warnings

## Goal

Reduce collision and low-signal completion risks for direct manager-workspace work without making the lightweight path mandatory-heavy.

## Implementation Contract

Design and implement only if it remains lightweight: optional direct work claim state for multi-session collision prevention, plus warning-level validation for changed_files that are missing or not changed. Do not hard-fail valid non-file or exploratory work.

## Acceptance

- There is an optional way to mark direct work in progress without forcing all direct work through a durable start step.
- complete_backlog_item can warn about changed_files that do not exist or do not appear changed without rejecting the completion.
- Queue output reflects any active direct claim clearly enough to avoid double pickup.
- Tests cover claim, release/cancel, stale recovery, and warning-only changed file validation.
