# MCP-010 Add Codex worker adapter skeleton

## Goal

Prepare the Codex harness adapter boundary without coupling task lifecycle to
Codex-specific chat behavior.

## Implementation Contract

Add a Codex adapter module that validates configuration, starts no live provider
in tests, maps known app-server event shapes into the generic worker event
model, and returns structured unsupported or configuration errors until the live
client is implemented.

## Acceptance

- Codex adapter configuration is typed and validated.
- Known event fixtures map into generic worker events.
- Missing executable or configuration returns actionable structured errors.
- Tests do not require a live Codex provider.
