# MCP-154 Expose storage backend readiness guidance

## Goal

Make the second-backend readiness path more inspectable by documenting and, where useful, surfacing capability-probe expectations for deciding whether a shared backend is justified.

## Implementation Contract

Build on the existing storage capability probe and ProjectState contract tests. Prefer documentation and deterministic inspection output improvements; do not implement a new backend in this item.

## Acceptance

- Storage documentation explains the readiness criteria for a future shared backend.
- Capability-probe or related inspection output points to contract-test expectations when backend readiness is discussed.
- No new backend implementation or backend-specific product dependency is introduced.
