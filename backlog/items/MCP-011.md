# MCP-011 Add Claude worker adapter skeleton

## Goal

Prepare the Claude harness adapter boundary with the same generic event and
result contract used by the runner.

## Implementation Contract

Add a Claude adapter module that validates configuration, normalizes stream JSON
or print-mode output fixtures into worker events, and returns structured
unsupported or configuration errors until live execution is enabled.

## Acceptance

- Claude adapter configuration is typed and validated.
- Known output fixtures map into generic worker events.
- Missing executable or configuration returns actionable structured errors.
- Tests do not require a live Claude provider.
